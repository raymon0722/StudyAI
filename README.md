# Study AI 1.0

교육용 AI 학습 도우미 프로토타입입니다.

## 포함 기능
- 홈 대시보드
- 가상 데이터로 학습한 성적 예측 모델
- 규칙 기반 공부 피드백
- 규칙 기반 주간 학습 계획 추천
- Decision Tree / Random Forest 성능 비교 화면

## 실행 방법
1. Python 환경에 패키지 설치
   `pip install -r requirements.txt`
2. 앱 실행
   `streamlit run app.py`

## 데이터 및 해석상 주의
이 앱은 코드 안에서 생성한 합성(가상) 데이터로 모델을 학습합니다.
따라서 예측 점수와 MAE/R²는 실제 학생 성적에 대한 검증 결과가 아닙니다.
교육용 프로토타입이며 실제 성적이나 학업 성취를 보장하지 않습니다.
